# AI Usage Statement

AI tools were used during the development of this project as follows:

- **Tools used:** Claude Code.
- **Purpose:** Coding support and documentation.
- **Parts of the project supported by AI:**
  - **Coding / debugging:** drafting and refactoring the model and experiment
    scripts (the VAE implementation, the Bayesian Transport Map training and
    evaluation pipeline, plotting utilities).
  - **Documentation:** writing the `README.md`, code comments and docstrings,
    and organizing the repository structure.
  - **Analysis / experimentation:** assistance in interpreting results and
    debugging training runs.

All AI-assisted code and text were reviewed, tested, and validated by the
author, who takes full responsibility for the correctness and integrity of the
submitted work. The underlying models (`batram`/`veccs` for the Bayesian
Transport Map, the `fields` R package for the Gaussian process) and the data
processing are based on the cited published work.
